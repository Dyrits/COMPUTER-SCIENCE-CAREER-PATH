# Computer Science Career Path

Projects from the Codecademy Computer Science career path.

## About The Project

The path covers programming fundamentals and computer science concepts with Python. This repository contains the section projects, one directory per section:

- 01 - Introduction to Programming
- 03 - Flow, Data, and Iteration
- 04 - Build a Tourism Recommendation Engine (The Boredless Tourist)
- 05 - Python Objects
- 06 - Create an Art Marketplace (Veneer)
- 07 - Linear Data Structures (Towers of Hanoi)
- 08 - Learn Complex Data Structures
- 12 - Learning Sorting Algorithms with Python (A Sorted Tale)
- 13 - How to Implement Search Algorithms with Python (Searchcademy)
- 14 - Graph Search Algorithms (SkyRoute - A Graph Search Program)
